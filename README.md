# Gassmann-Fluid-Substitution-single-layer-case-
Fluid substitution modelling by using Gassmann's equation (1951) with the assumption that the fluid modulus is an isostress average of the moduli of the liquid and gaseous phases.
For a single layer case, run FSM.m file, that will provide seismic velocities and moduli at certain water saturation. The function ahmedFSM.m is based two fluid phases water/oil.
While the file FSM_sw_iteration.m provide the seismic velocities and moduli as a function of water sautation.
